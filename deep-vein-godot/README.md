# DEEP VEIN — Godot 4 3D Mining Prototype

**Prototype v0.1** — 자유 굴착 + 자연 동굴 + 노출/매장 광석. HTML이 아닌 **Godot 4.3+ GDScript 프로젝트**입니다.

> 🧪 엔진 실행 검증을 마치지 못한 소스 프로토타입입니다. Godot 에디터에서 실행 후 문제가 있으면 해당 오류 메시지를 남겨주세요.

## 시작 방법

1. **Godot 4.3 이상** (일반 GDScript 버전) 설치. 가능하면 4.5.x 사용.
2. 프로젝트 매니저의 **Import**에서 이 폴더의 `project.godot` 파일 선택.
3. 상단 ▶ **Run Project (F6가 아닌 F5)** 실행.
4. 화면 로딩 직후 땅과 동굴 및 광석이 절차 생성됩니다. 보통 초기 생성이 가장 무겁습니다.

### Android (모바일 Godot 에디터)
- Godot 4 Android Editor에서 폴더를 풀고 `project.godot`를 임포트하세요.
- 프로젝트를 실행하면 **왼쪽 조이스틱 이동**, **오른쪽 위 화면 드래그로 시점 회전**, 오른쪽 버튼으로 채굴·점프·탐지·판매·업그레이드·새 광산을 조작합니다.
- 안드로이드용 APK가 아니라 **에디터에서 편집/실행할 수 있는 프로젝트**입니다.
- 성능이 낮으면 `scripts/terrain.gd`의 `GRID`(지형 세밀도) / `COUNT` (영역)를 조절하세요. `GRID` 변경 시 CHUNK가 달라지므로 생성 범위도 함께 바뀝니다.

## 핵심 시스템

- **삼차원 SDF 복셀 채굴**: 큐브 블록 대신 Marching Tetrahedra 메시로 곡면 암벽과 둥근 구덩이/터널을 만듭니다.
- **반복 가능 지형**: 최초에 3개 천연 동굴 및 연결 통로를 생성합니다. 달라지는 시드의 노이즈로 바위 형상이 변합니다. 규모가 작은 시제품이라 동굴 토폴로지는 고정입니다.
- **암반 매장 광석**: 자연 동굴 가장자리 암반 내부에 광물을 배치하므로 **땅을 파서 숨은 광물을 드러낼 수 있습니다**.
- **동굴 노출 광석**: 이미 뚫려 있는 동굴의 벽·바닥·천장에도 채굴 가능한 결정이 붙어 있습니다.
- **희귀 광석**: Coal, Copper, Iron, Gold, Azure, Starlight. 광석 판매 → 강화 루프.
- **모바일 조작 UI**: 가상 조이스틱, 드래그 시점, 버튼을 사용합니다.

## 기술적 범위 및 현재 한계

- 자동 세이브/로드, 전투, 사망, 로그라이크 영구 성장, 붕괴 물리, 멀티플레이는 **아직 구현되지 않았습니다**.
- 광산의 벽/동굴 배치는 거의 고정이며 **광물 위치와 표면 모양**이 시드마다 랜덤으로 달라집니다. 본격적인 절차적 무한 동굴 생성은 후속 단계입니다.
- 지형은 **유한한 38×19×38m 내외** 공간입니다. 청크별 충돌 메시를 동적 재생성하며, 굴착 시 기기 성능에 따라 잠깐 끊길 수 있습니다.
- 광석 자체는 독립 오브젝트이고 지형 메시 내부에 물리적으로 포함된 광맥 덩어리는 아닙니다. 향후 불규칙한 부피 광맥 생성으로 발전시키면 좋습니다.
- 디버그 소스 버전이며 실제 APK 내보내기 테스트는 별도로 필요합니다.

## 파일 구조

```
project.godot
scenes/main.tscn
scripts/main.gd       # 게임 루프, 판매/업그레이드, 광물 배치
scripts/terrain.gd    # SDF 지형 생성, 청크/굴착, 충돌 메시
scripts/ore.gd        # 채광 가능한 6종 광석
scripts/player.gd     # FPS 이동/시점, 충돌, 손전등
scripts/hud.gd        # 게임 HUD, 모바일 버튼
scripts/joystick.gd   # 멀티터치 이동
```
