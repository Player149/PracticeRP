# DEEP VEIN — Dig Only (Godot 4)

기존 동굴, 광물, 상점, 플레이어 시스템을 모두 제거한 **굴착 전용** 테스트 버전입니다.

Godot 4.3 이상에서 이 폴더의 `project.godot`을 엽니다. 실행하면 3D 갈색 지형과 작은 샘플 구덩이가 바로 표시됩니다.

조작:
- 모바일: 땅을 터치·누르기·드래그하여 굴착
- PC: 왼쪽 마우스를 클릭·누르기·드래그하여 굴착
- RESET: 초기화, ZOOM + / -: 확대축소
- PC: WASD/화살표 카메라 이동, 마우스 휠 줌, R 초기화

이 버전은 높이맵 기반이므로 **구덩이와 경사면은 실제로 변하지만 터널·천장 굴착은 지원하지 않습니다**. 첫 화면 표시와 모바일 굴착 입력을 검증하기 위한 가벼운 재구성입니다.
