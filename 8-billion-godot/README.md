# 8 BILLION — Godot 4 prototype

Open this folder in Godot 4.3+ (Import project.godot), then press F6/F5.

Controls: A/D move, W/Space jump, J attack, K heavy attack, L dash, E enter/exit building, R restart.
All visuals are drawn procedurally in main.gd; no external assets required.
The prototype includes fleeing civilians, ranged soldiers, grenadiers, building interiors and destruction, soul harvesting, and a scrolling city. It is a gameplay prototype, not a polished game.

The separate `8-billion/index.html` is the earlier HTML prototype. This folder is the actual native Godot project.
