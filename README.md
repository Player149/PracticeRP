# Dig — Godot 4 base project

This is a **clean starting point** for a new 3D digging prototype. It contains only a simple startup scene, a camera, a directional light, a static ground mesh, and a marker cube. There is **no digging, character control, or game logic**.

## Open

1. Use Godot 4 (Compatibility renderer).
2. Import the `project.godot` file in this directory.
3. Run the project. A static ground surface and a single cube should be visible.

The main scene is `res://scenes/main.tscn`. There are no scripts or external assets.
